How it works.

1. Write short classes

Layout f ac jb gr c3, spacing p4 mt6 g3 on a 0–10 scale, type t0–t9 b sb tt, color roles ci cm bs ba, shape r rp bd. Variants: h- hover, m- ≥768px, l- ≥1024px.

2. Generate only what you use

npx @labs_kai/sscss page.html --write

One command reads the page, writes the rules it needs into <style data-sscss> in <head>, and tells you about any class it doesn't know. No build step, no stylesheet request, nothing to purge.

3. Add your own

Anything the vocabulary doesn't cover goes in the page's own <style>; the generator leaves it alone. Tokens live in :root — change six variables and the whole page, dark mode included, follows.

Motion, the basic package.

Eight utilities, transform and opacity only, all off under prefers-reduced-motion: an-in for inserted elements, an-rise scroll entrance, an-spin, an-grow for meters, an-fx button feedback, an-tone for theme changes, an-vt to tune view transitions — and an-sea, a CSS ocean for a hero, cut from one tiny SVG tile and colored by the tokens. They exist because a Minim page needed exactly these.

Use it.

Generate (recommended)

npm i -D @labs_kai/sscss
npx sscss page.html --write     # inline only what the page uses
npx sscss page.html --check     # exit 1 on unknown classes
npx sscss --list                # the cheat sheet

Pair it with Minim for state and events: Minim lite and the sscss core are 1.6 KB together, inlined, and the page makes one request.

Or just load it

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@labs_kai/sscss@1/dist/sscss.base.css">

Every utility, 2.1 KB gzipped (3.6 KB with the responsive variants, sscss.css); sscss.core.css is the 300 B reset + tokens on its own. Still smaller than this one page in Tailwind.

Agents: the repository ships a skill — npx skills add hertonwork/sscss — with the vocabulary, the rules, and the checks.
